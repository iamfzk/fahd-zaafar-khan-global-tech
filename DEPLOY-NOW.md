# Deploy Abhi – 2 Minute

## Option A: Netlify Drop (koi account / repo connect nahi chahiye)

1. **https://app.netlify.com/drop** kholo
2. Apne folder **fahd-zaafar-khan-global-tech** ko **drag & drop** karo (purra folder jisme index.html, style.css, assets hai)
3. Netlify upload karke **turant link de dega** – wahi tumhara live link

---

## Option B: GitHub Pages (repo already hai)

1. **https://github.com/iamfzk/fahd-zaafar-khan-global-tech/settings/pages** kholo
2. **Branch** dropdown pe click karo (jahan "None" hai)
3. **master** select karo → **Save**
4. 2–3 minute baad ye link kholo: **https://iamfzk.github.io/fahd-zaafar-khan-global-tech/**

---

## Option C: Netlify + GitHub (auto deploy)

1. **https://app.netlify.com** → Log in with GitHub
2. **Add new site** → **Import an existing project** → **GitHub** → **fahd-zaafar-khan-global-tech** choose karo
3. **Publish directory:** `.` (sirf dot) | Build command khali
4. **Deploy site** → 1 minute baad link milega

---

Sabse fast: **Option A** – bas app.netlify.com/drop pe jao, folder drag karo, link mil jayega.
